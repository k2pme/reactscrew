# OpenAPI Generated Example

This example illustrates the contract-driven path:

1. Start from [openapi.json](/home/clodlin/reactscrew/examples/openapi-generated/openapi.json)
2. Generate screws with:

```bash
npm run build
npm run generate:openapi -- ./examples/openapi-generated/openapi.json ./examples/openapi-generated/generated/userScrews.js
```

3. Import the generated screws in an application layer.

The generated file in this example is already committed for inspection.
